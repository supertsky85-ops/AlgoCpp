# AlgoCpp 本地 C++ 算法练习桌面版

## 启动

双击 `start.bat`。需要 Python 3（含 tkinter），无第三方 Python 依赖。本机已检查可用。

## 配置 C++ 编译器

程序是调用 GCC/Clang 的轻量编辑器，不包含编译器工具链。

本机已经配置完成：使用 `C:\code\AlgoCpp\toolchain\mingw64\bin\g++.exe`，版本 G++ 7.5.0，默认 C++17。已通过 AlgoCpp 实际编译运行验证，包含标准输入输出、STL vector/sort 和 C++17 结构化绑定。该编译器版本不支持 C++20/23，请选择 C++17 或更早标准。若程序已打开，请关闭后重新启动以加载配置。此绝对路径仅适用于本机；其他电脑按以下步骤配置。

1. 按 https://www.msys2.org/ 安装 MSYS2。
2. 打开 **MSYS2 UCRT64**，执行 `pacman -S mingw-w64-ucrt-x86_64-gcc`。
3. 在 AlgoCpp 点击“设置编译器”，选择 `C:\msys64\ucrt64\bin\g++.exe`（自定义安装目录则相应调整）。

官方说明：https://www.mingw-w64.org/getting-started/msys2/

也支持有完整 C++ 标准库环境的 clang++。不支持直接调用 MSVC cl.exe。默认示例的 bits/stdc++.h 适用于 GCC；使用其他工具链时可以改成标准头文件 iostream、vector 等。

## 功能与快捷键

- C++ 语法高亮、行号、撤销重做（Ctrl+Z / Ctrl+Y，取决于 Tk 默认绑定）。
- 小括号、中括号、花括号和引号配对；选中文字后输入左括号可包裹选区。
- 花括号内回车自动缩进，退格成对删除，Tab 插入四个空格。
- 常见关键字、STL 名称、当前文档标识符补全。输入两个字符自动弹出，Ctrl+Space 手动触发，上下键选择，Tab/Enter 接受，Esc 关闭。
- fori、forr、sort、lower_bound 等代码片段。完整单词后可按 Ctrl+Space 查看对应片段。片段中的 n、a、value、container 等占位名称需要自行修改。
- Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存；UTF-8 文件。
- F7 编译，F5 编译并运行；可选 C++11/14/17/20/23，实际支持由安装的编译器版本决定。
- 下方填入标准输入，右侧查看输出和编译错误；双击 GCC/Clang 的行列错误信息定位代码。
- 运行超时 5 秒、编译超时 60 秒；“停止”终止当前直接启动的进程。
- 编译器位置和语言标准保存在同目录 settings.json。

## 错误定位与调试（已接入 GDB 9.1）

- 按 F7/F5 后，当前源文件的编译错误行会显示红色背景，警告行显示黄色背景。在“错误 / 警告”标签页点选信息，跳转至对应行列。头文件的错误保留在输出中，不会错误地标记当前文件。
- 编辑后自动移除旧编译标记；这是编译结果提示，不是实时语义检查。
- 点击左侧行号或按 F9 添加/移除断点，红点表示断点。空行、注释行的断点可能被 GDB 移到后面的可执行行，输出中会显示实际行号。编辑时断点位置跟随文本移动；打开或新建文件会清空断点。
- F6 开始调试，使用 `-g -O0` 重新编译，首先暂停在 main 的第一条可执行语句。无需先保存文件。黄色背景表示下一条将执行的语句。
- F8 继续至下一个断点；F10 逐过程；F11 进入函数；Shift+F11 跳出当前函数。
- 调试暂停时也可按 F5 继续。普通运行开始和调试结束时自动显示“输出”标签页；输出窗口已修复被标签页遮盖的问题。
- 在“调试：局部变量 / 调用栈”标签页查看当前栈帧的局部变量和值，以及最多 16 层调用栈。暂停时刷新；未初始化的变量可能显示无意义的值。复合类型当前显示类型摘要，不提供 STL 容器树形展开或自定义监视表达式。
- 点击“停止”结束调试，连同被调试的子进程一起结束；调试期间代码只读，结束后恢复编辑。
- 调试使用左下方预先填入的标准输入；程序输出在调试结束时汇总显示。进入 STL / 系统函数后，可能暂停在外部源码，当前编辑器不会将外部行号标到主文件；可用跳出返回自己的代码。
- 本机已自动配置同工具链目录中的 gdb.exe。更换工具链时可点击“设置 GDB”选取匹配的调试器。调试运行没有普通运行的 5 秒限制，需要时点击停止。

快速试用：打开 `debug_example.cpp`，标准输入填 `3`，在 `int b = twice(a);` 一行点击行号设置断点。按 F6，再按 F8，会暂停在函数调用前；按 F11 进入 twice，按 Shift+F11 返回。最后按 F8，程序输出 `7`。

## 多组样例自动测试

点击“样例测试 Ctrl+Enter”打开管理窗口。首次内置两组 A+B 示例，可直接使用主窗口默认代码测试。

1. 点击新增，为每组填写名称、输入和期望输出；切换样例时自动保留编辑。
2. 点击“测试全部”或在样例窗口按 Ctrl+Enter。使用当前编辑器代码，只编译一次，每组独立启动程序。结果列表显示 AC（通过）、WA（不一致）、TLE（超时）、RE（非零退出）、CE（编译错误）或 OLE（输出过大）。
3. 点击任意样例查看实际输出及差异。默认忽略空白，按非空白输出项逐个精确比较；严格模式仅统一 CRLF/LF 换行，保留空格和末尾换行差异。不提供浮点误差容限或 special judge。
4. 每组限时可设为 0.1～60 秒；时间为本机进程启动到结束的墙钟耗时，包含系统开销，不等于评测平台耗时。stdout+stderr 合计超过 1 MiB 判 OLE，展示内容会截断。
5. 样例集运行前及窗口关闭时保存到软件目录的 samples.json；可导入/导出 JSON 保存不同题目的样例集。导入会替换当前列表，需保留当前题目时先导出。结果每次重新生成。
6. 测试期间可切换查看样例，但不能修改；点击停止会结束当前直接子进程并跳过剩余样例。普通运行、调试和样例测试不能同时执行。

JSON 格式示例：

```json
{"version": 1, "mode": "忽略空白", "timeout": "5", "cases": [{"name": "样例 1", "input": "3 5\n", "expected": "8\n"}]}
```

## 安装位置

完整应用迁移到 `C:\code\AlgoCpp`，双击该目录的 start.bat 启动。配置、样例及复制的 G++ / GDB 工具链均放在该目录；本机 Python 仍用于启动界面。原 MWORKS 工具链保持原位，避免影响其他软件。附带工具链时优先使用 toolchain/mingw64/bin 下的编译器和调试器，路径相对软件目录解析。

## 当前边界

这是轻量单文件练习工具。补全基于词表和文档单词，不具备 VS2022 的类型推断、函数签名提示、实时语义诊断和项目管理。已支持基础 GDB 调试，但不提供条件断点、监视表达式、多文件源码视图或多线程调试界面。暂未接入 clangd；成员函数候选不按对象类型过滤。

一次编辑一个源文件，编译临时副本，不会自动保存当前文件。已保存文件所在目录作为运行目录与本地头文件搜索目录；未保存文件在临时目录运行。标准输入一次提交，不支持交互式终端。输出会在程序结束后显示，暂不支持海量输出截断。仅用于运行自己信任的练习代码，进程以当前用户权限执行。
