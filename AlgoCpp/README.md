# AlgoCpp

面向算法练习与竞赛刷题的 Windows 轻量 C++ 桌面 IDE。

使用 Python / Tkinter 构建界面，调用本地 GCC / Clang 编译代码，通过 GDB 提供基础调试。支持括号匹配、自动补全、代码格式化，以及多组样例自动测试与输出比对。

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 启动入口 | 根目录的 `打开 AlgoCpp.bat` 双击启动；`创建桌面快捷方式.bat` 一键生成桌面图标 |
| 代码编辑 | 语法高亮、行号、关键字与 STL 名称补全、按容器类型的成员补全、代码片段 |
| 多标签页 | 快速新建标签页，每个标签独立撤销、断点和编译诊断；未保存也能运行 |
| 括号辅助 | 自动配对、按嵌套层级着色、对应括号高亮、未匹配提示 |
| 编辑操作 | 自动缩进、多行缩进、拖动移动选区、撤销与回退 |
| 一键排版 | 使用 clang-format 统一四空格缩进、空格和换行 |
| 编译运行 | 本地编译、预设标准输入、输出显示、编译错误定位 |
| 基础调试 | 断点、单步进入/跳出、逐过程、局部变量与调用栈 |
| 样例测试 | 编译一次测试多组样例，显示结果与输出差异 |
| 窗口布局 | 高 DPI 显示、字体缩放、分区大小拖动、窗口置顶 |

## 快速开始

### 1. 准备环境

- Windows 桌面环境。
- Python 3.10 或更新版本，安装时包含 Tcl/Tk，并让 `python` 命令可用。本项目已在 Python 3.13 环境运行验证。
- GCC / MinGW-w64，或配置好 C++ 标准库的 Clang。
- 可选：GDB，用于调试；clang-format，用于格式化。

界面与应用逻辑仅使用 Python 标准库，无需安装额外的 Python GUI 库。编译器、调试器和格式化工具是独立的外部程序。

### 2. 启动软件

下载或克隆仓库并解压后，直接双击仓库根目录的 **`打开 AlgoCpp.bat`**，它会进入本目录并调用 `start.bat`。想放到桌面时，双击仓库根目录的 **`创建桌面快捷方式.bat`**，会在桌面生成指向本目录 `start.bat` 的 **AlgoCpp** 快捷方式。也可以在本目录双击 `start.bat`，或在终端执行：

```powershell
python algocpp.py
```

### 创建桌面快捷方式（Windows）

完成环境和编译器配置后，可以把启动入口放到桌面，以后无需打开项目文件夹。

**最快的方法**：双击仓库根目录的 **`创建桌面快捷方式.bat`**。脚本会在桌面生成 `AlgoCpp.lnk`，指向本机的 `AlgoCpp/start.bat`，不需要手动选择路径；如果桌面已有同名快捷方式，会直接更新它，不会重复生成。移动或重命名仓库文件夹后，重新运行一次该脚本即可刷新快捷方式。

也可以手动操作：

1. 在仓库根目录右键 **`打开 AlgoCpp.bat`**；Windows 11 需要先点击“显示更多选项”。
2. 选择 **发送到 → 桌面快捷方式**。
3. 桌面会出现“打开 AlgoCpp - 快捷方式”，可重命名为 **AlgoCpp**。
4. 以后双击桌面图标即可启动。

还可以右键桌面 **新建 → 快捷方式**，点击“浏览”，选择仓库根目录的 `打开 AlgoCpp.bat`（或本目录的 `start.bat`），再填写名称。

仓库没有附带现成的 `.lnk` 文件：Windows 快捷方式保存的是创建者电脑上的绝对路径，别人下载解压后多半会失效。因此由 `创建桌面快捷方式.bat` 在下载者的电脑上现场生成，或由系统“发送到桌面快捷方式”生成，路径才正确。创建快捷方式不会安装 Python 或编译器，仍需先按本文完成环境配置；移动或重命名仓库文件夹后，需要重新创建快捷方式。

### 3. 配置编译器

已有 MinGW-w64 的用户，点击“设置编译器”，选择 `g++.exe` 即可。

需要安装时，可按 [MSYS2 官方指南](https://www.msys2.org/) 安装 MSYS2，然后在 **MSYS2 UCRT64** 终端执行：

```bash
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-gdb
```

安装到默认位置时，在 AlgoCpp 中选择：

```text
编译器：C:\msys64\ucrt64\bin\g++.exe
调试器：C:\msys64\ucrt64\bin\gdb.exe
```

编译器可从界面手动选择；调试时尝试使用编译器同目录下的 GDB，也可点击“设置 GDB”指定。建议使用同一套工具链中的编译器与调试器。[GDB 软件包说明](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-gdb)

默认语言标准为 C++17。界面提供 C++11 / 14 / 17 / 20 / 23，实际可用标准由编译器决定；旧版 GCC 7.5 应选择 C++17 或更早标准。

默认代码使用 GCC 常见的 `bits/stdc++.h`。使用不提供该头文件的工具链时，请改为 `iostream`、`vector` 等标准头文件。当前不直接支持 MSVC `cl.exe`。

### 4. 运行第一段代码

启动时默认代码为 A+B。在左下方“标准输入”中填写：

```text
3 5
```

按 **F5**，软件会编译并运行，在输出页显示 `8`。只编译可按 **F7**。

## 编辑与括号匹配

- 输入 `(`、`[`、`{` 或引号时自动补齐另一端；输入光标处已有的右括号会直接跳过。
- 选中文字后输入左括号，可用一对括号包裹选区；空括号之间按退格可成对删除。
- `()`、`[]`、`{}` 按嵌套层级着色。点击括号、选中单个括号或将光标放在旁边时，两端同时高亮；光标位于块内部时，可高亮最近的包围括号。
- 匹配时跳过注释、字符串、字符和 C++ 原始字符串中的括号。
- 不完整代码会尝试结合缩进恢复花括号归属。例如删除内层 `if` 的结束括号时，保留可根据缩进识别的外层 `for`、`main` 配对。无法判断的括号显示红底和提示；该恢复是编辑辅助，不代替编译器语法检查。
- 回车沿用当前缩进，在括号中展开时增加四空格；Tab / Shift+Tab 支持多行缩进与反缩进。
- 输入两个字符可触发关键字、STL 名称及当前文档标识符补全，Ctrl+Space 可手动触发。候选用方向键选择，Tab / Enter 接受，Esc 关闭。
- 在容器变量后输入 `.` 或 `->` 会识别它的声明类型，只列出该容器的成员。例如 `map<int, int> mp;` 后输入 `mp.` 会给出 `find`、`count`、`lower_bound`、`upper_bound`、`erase`、`insert` 等；选中 `lower_bound` 会插入 `lower_bound(x)`。函数局部变量、参数、全局变量、嵌套模板、`std::` 前缀和 `using` 别名都可识别。该推断基于文本声明，不经过编译器；未识别的对象仍按通用词表补全。
- 支持 `fori`、`forr`、`sort`、`lower_bound` 等片段；完整片段名称后可按 Ctrl+Space 选择。片段中的变量名需要按题目修改。
- 先选中代码，再从选区内部按住左键拖到目标位置，松开即可移动。拖回选区内不作修改，Esc 取消，靠近上下边缘可自动滚动。
- 工具栏“撤销”回到上一步；“回退”恢复刚撤销的操作。整段拖动、格式化和多行缩进各支持一次撤销。

## 多标签页与快速新建

- 点击工具栏“新建 Ctrl+N”、标签栏右侧的“+ 新建”，或按 **Ctrl+N**，会在后台新增一个默认模板标签页，原来的代码不会被清空，当前标签也不会自动切走；点击新标签才会切换过去。需要创建后立即切换时按 **Ctrl+Shift+N**。
- 每个标签页有独立的内容、撤销历史、断点、光标位置和编译诊断标记。标签上的 `●` 表示尚未保存；点击标签切换，点击 `×`、按 **Ctrl+W** 或鼠标中键关闭。
- 未命名标签的编号会复用：关闭“未命名 2”后再新建，新标签仍是“未命名 2”；编号被占用时才继续递增。
- 关闭有改动的标签页会询问是否保存；取消则不关闭。关闭最后一个标签页后会自动补一个空白标签页。
- **打开**文件时，如果当前是未修改的空白标签页就直接载入，否则新开一个标签页，不会覆盖已编辑的内容。
- 未保存的标签页可以直接按 **F5** 运行：编译和运行都在临时目录中进行，不需要先创建或保存文件。运行或调试期间标签页暂时不能切换，结束后恢复。

## 一键格式化

点击“格式化”或按 **Ctrl+Shift+F**，整理整个文档：四空格缩进、规范空格与换行，保持头文件顺序。可一次撤销，格式化不会自动保存源文件。

需要安装 clang-format。本项目使用 **21.1.8** 验证，可通过 [PyPI 的 clang-format 包](https://pypi.org/project/clang-format/21.1.8/) 安装：

```powershell
python -m pip install clang-format==21.1.8
clang-format --version
```

确保 `clang-format` 命令位于 PATH 中；也可以将可独立运行的 `clang-format.exe` 放到 `toolchain/formatter/`。应用优先使用该目录，再从 PATH 查找。

存在未匹配括号或格式化工具无法处理的语法时，会提示失败。运行和调试期间禁止格式化。

## 编译错误与调试

编译后，当前文件的错误行显示红色背景，警告行显示黄色背景；可在“错误 / 警告”页选择信息，或双击输出中的行列信息跳转。编辑源码后会清除过期标记。

调试操作示例：

1. 打开 [`debug_example.cpp`](debug_example.cpp)，标准输入填写 `3`。
2. 在 `int b = twice(a);` 一行点击行号，或按 F9 设置断点。
3. 按 F6 开始调试，程序先暂停在 `main`。
4. 按 F8 继续到断点，F11 进入 `twice`，Shift+F11 跳出。
5. 按 F8 运行到结束，输出为 `7`。

调试使用 `-g -O0` 编译，当前暂停行显示黄色背景。可在调试页查看局部变量及最多 16 层调用栈；调试期间代码只读。

调试标准输入需要提前填写，输出在结束时汇总显示。调试运行不采用普通运行的 5 秒限制，可点击“停止”结束。

## 多组样例测试

点击“样例测试”或按 **Ctrl+Enter** 打开测试窗口：

1. 新增样例，填写名称、输入与期望输出。
2. 点击“测试全部”，使用当前编辑器内容编译一次，并为每组样例独立启动程序。
3. 查看每组判定、耗时和实际输出；点选样例查看输出差异。

| 结果 | 含义 |
| --- | --- |
| AC | 输出通过比对 |
| WA | 输出不一致 |
| CE | 编译错误 |
| RE | 程序以非零退出码结束 |
| TLE | 超过每组运行时限 |
| OLE | 标准输出与错误输出合计超过 1 MiB |

默认“忽略空白”模式按非空白项逐个比较；“严格比较”仅统一 Windows / Unix 换行，保留空格与末尾换行差异。不支持浮点误差容限或自定义判题器。

每组时限可设置为 **0.1～60 秒**，显示本机墙钟耗时。样例集运行前、窗口关闭时保存到 `samples.json`；支持 JSON 导入与导出。导入会替换当前列表，需要保留原样例时请先导出。

```json
{
  "version": 1,
  "mode": "忽略空白",
  "timeout": "5",
  "cases": [
    { "name": "样例 1", "input": "3 5\n", "expected": "8\n" },
    { "name": "样例 2", "input": "-2 7\n", "expected": "5\n" }
  ]
}
```

## 窗口与分屏

- 支持 Windows 系统 DPI 适配；默认大小按 1200×820 逻辑尺寸及系统缩放计算，小屏自动限制到屏幕内。
- 拖动窗口边缘或四角调整整个 IDE 大小；工具栏在窗口变窄时自动换行。
- 拖动横向分隔线，调整代码区与输入输出区的高度；拖动纵向分隔线，调整标准输入与输出区的宽度。分隔线为细浅灰线。
- 工具栏 A− / A+ 调整字体；代码、输入输出和样例窗口共用字体设置。
- “最大化 / 还原”切换窗口大小；“窗口置顶”方便分屏（每次启动都关闭，手动开启只对本次运行有效），样例窗口同步置顶状态。
- 字号在正常退出时保存到 `settings.json`。不同缩放比例的显示器之间移动窗口后，如显示不一致，可在目标屏幕重新启动。

## 项目结构与技术

```text
AlgoCpp/
├─ algocpp.py          # 主界面、多标签页、文件操作、编译运行、补全
├─ intellisense.py     # 容器声明识别与按类型成员补全
├─ editor_features.py  # 括号匹配、缩进、格式化、选区拖动、撤销回退
├─ display_features.py # DPI、字体缩放、工具栏换行、窗口置顶
├─ debug_ui.py         # 编译诊断、断点和调试界面
├─ debugger.py         # GDB/MI 通信与结果解析
├─ samples.py          # 多组样例管理、运行与输出比对
├─ debug_example.cpp   # 调试示例
├─ samples.json        # 示例样例集 / 本地样例数据
├─ start.bat           # Windows 启动脚本
└─ README.md
```

仓库根目录的 `打开 AlgoCpp.bat` 会进入本目录并调用 `start.bat`；根目录的 `创建桌面快捷方式.bat` 可在桌面生成快捷方式；直接双击本目录的 `start.bat` 也可以启动。

主要技术为 Python 标准库：`tkinter/ttk` 构建界面，`subprocess` 调用工具链，线程与队列协调后台任务，JSON 保存配置与样例。调试通过 **GDB/MI** 协议；格式化调用 **clang-format**。

应用还支持以下可选的本地工具目录，优先于手动配置的编译器及调试器路径：

```text
toolchain/
├─ mingw64/bin/g++.exe
├─ mingw64/bin/gdb.exe
└─ formatter/clang-format.exe
```

编译器运行还需要配套头文件、库及 DLL，不能只复制 `g++.exe`。源码仓库不要求附带这些工具，使用者可按上述步骤自行安装。

## 当前范围

- 定位为轻量的多标签单源文件算法练习工具。补全基于词表、文档标识符与轻量声明推断：能识别常见 STL 容器变量的成员，但暂未接入 clangd，不提供完整类型推断、表达式求值或实时语义诊断。
- 基础调试不包含条件断点、自定义监视表达式、STL 容器树形展开、多文件源码视图及多线程调试界面。
- 编译当前标签页内容的临时副本，不自动保存源码。已保存文件的目录用于运行及本地头文件搜索；未保存或新建的标签页使用临时目录，仍可直接运行。
- 标准输入在运行前一次填写，输出在结束后汇总显示，暂不提供交互式终端。普通运行限时 5 秒，编译限时 60 秒；样例测试有独立时限及输出上限。
- 普通运行、调试与样例测试不能同时执行。程序运行使用当前用户权限，不提供代码沙箱。

## 上传到 GitHub

提交本 README、仓库根目录的 `打开 AlgoCpp.bat` 和 `创建桌面快捷方式.bat`、上述源码文件、`start.bat`、调试示例和适合公开的示例样例集。新增的 `intellisense.py`、`editor_features.py`、`display_features.py` 也需要一并提交，否则启动时会缺少模块。

建议在仓库根目录创建 `.gitignore`：

```gitignore
toolchain/
__pycache__/
*.py[cod]
*.exe
*.o
settings.json
*_verification.txt
verification.txt
```

`settings.json` 为自动生成的本机配置；工具链、缓存与编译产物无需随源码上传。若文件已被 Git 跟踪，新增忽略规则不会自动取消跟踪，需要在提交前单独处理。
